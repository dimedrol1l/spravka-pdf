# Разделение PDF-справок

Настольное приложение разделяет многостраничный PDF на отдельные файлы — по
одной странице на справку — и называет каждый файл по номеру справки. Оно
создано для сокращения ручной работы при обработке отсканированных документов.

Идея и описание пользовательского сценария принадлежат владельцу проекта.
При реализации использовался ИИ. По оценке владельца, инструмент сокращает
время этой работы примерно на 90%; систематический замер не проводился.

## Возможности

- Сначала извлекает номер из текстового слоя PDF.
- Для сканов распознаёт текст локальным Tesseract OCR.
- Автоматически ищет номера длиной от 2 до 6 цифр или использует выбранную
  длину.
- Сохраняет каждую страницу в отдельный PDF и добавляет суффикс, если номер
  уже встречался.
- Не перезаписывает существующие файлы: выбирает следующее свободное имя.
- Отмечает страницы без найденного номера и некоторые менее надёжные совпадения
  для ручной проверки.
- Показывает номер страницы, найденный номер, источник распознавания, отметку
  о ручной проверке и имя созданного файла.
- Обрабатывает документы локально и не загружает PDF в сетевой сервис.

## Как устроено

Интерфейс на PySide6 передаёт обработку PDF в фоновый поток. Прикладной модуль
обходит страницы, доменные правила ищут номер справки, а инфраструктурный слой
извлекает текст, запускает OCR и сохраняет страницы. Для OCR анализируется
верхняя правая часть страницы.

Основной стек: Python, PySide6, PyMuPDF, Pillow, pytesseract и Tesseract OCR.

## Запуск из исходников

Нужен Python 3.11 или новее. Для распознавания сканов установите Tesseract OCR
с языковыми данными `rus` и `eng`. В проект не включены установочные файлы и
бинарники Tesseract.

### Windows

Создайте окружение и установите зависимости:

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Если Tesseract установлен не в стандартный каталог, укажите путь к папке с
`tesseract.exe`.

В командной строке Windows:

```bat
set TESSERACT_HOME=C:\Program Files\Tesseract-OCR
.venv\Scripts\python app_gui.py
```

В PowerShell:

```powershell
$env:TESSERACT_HOME = "C:\Program Files\Tesseract-OCR"
.venv\Scripts\python app_gui.py
```

Если Tesseract находится в стандартном каталоге, переменную `TESSERACT_HOME`
задавать не нужно. Варианты установки описаны в
[документации Tesseract](https://tesseract-ocr.github.io/tessdoc/Downloads.html).

### macOS

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app_gui.py
```

Установите Tesseract с языками `rus` и `eng`. Поддержка Intel Mac проверена;
Apple Silicon отдельно не тестировался.

## Сборка приложения

Собирайте приложение на целевой операционной системе: PyInstaller не создаёт
Windows-сборку на macOS и наоборот.

- **Windows x64:** установите Python 3.11+ и Tesseract с языками `rus` и `eng`,
  затем запустите `build.bat`. Сборка включает локальные файлы Tesseract.
- **macOS Intel:** установите Python 3.11+ и Tesseract с языками `rus` и `eng`,
  затем выполните `sh build_macos.sh`. В macOS-пакет Tesseract не включён — он
  устанавливается отдельно.

Оба сценария выполняют OCR-самопроверку на искусственном PDF без персональных
данных и сохраняют архив в `releases/`. Существующий архив сборки не
перезаписывается.

По сообщению владельца, предыдущая Windows-сборка работала; последнюю версию
сборочного сценария нужно проверить на Windows. Сборка и запуск Intel-версии
macOS проверены. Поддержка Apple Silicon пока не заявляется.

## Проверки

Запустить тесты обработки PDF:

```sh
python3 -m unittest discover -s tests -v
```

OCR-самопроверка сборки запускается автоматически. Она создаёт собственный
искусственный документ и не использует реальные справки.

## Ограничения

- За один запуск обрабатывается один входной PDF.
- OCR проверяет фиксированную верхнюю правую область; документы с другой
  разметкой могут потребовать ручной проверки.
- Отметка ручной проверки основана на эвристике. Отсутствие отметки не
  гарантирует, что распознавание безошибочно.
- Если номер не найден, файл получает имя вида
  `page_001_NO_NUMBER.pdf`.
- Перед использованием проверьте созданные файлы, особенно отмеченные для
  ручной проверки.
