Разделение PDF-справок
======================

Windows
-------
1. Распакуйте архив целиком.
2. Запустите START.bat.
3. Выберите исходный PDF и папку результата.
4. Для сканов оставьте включённым OCR. OCR уже включён в Windows-архив.
5. Нажмите «Разделить PDF» и сверьте строки «Проверить вручную».

macOS
-----
1. Распакуйте архив.
2. Установите Tesseract OCR с языками rus и eng, если он ещё не установлен.
3. Откройте RazdelenieSpravok.app. Если macOS не даёт открыть приложение,
   используйте настройки безопасности macOS для подтверждения запуска.
4. Выберите исходный PDF и папку результата.
5. Нажмите «Разделить PDF» и сверьте строки «Проверить вручную».

Результат
---------
Каждая страница исходного PDF сохраняется в отдельный PDF с номером справки
в имени. Если номер не распознан, имя содержит номер страницы и NO_NUMBER.
Одинаковые номера получают суффикс. Уже существующие файлы не заменяются:
для нового результата выбирается следующий свободный суффикс.

Оригинал не изменяется. Распознавание и разделение выполняются на компьютере.
OCR может ошибаться: перед использованием результата проверьте строки,
помеченные «Проверить вручную».
